# PalBro

**A lightweight, responsive companion web app for Palworld.**

PalBro is a server-rendered web application providing a searchable encyclopedia of Pals, stats tracking, and a deployed base management dashboard for Palworld players.

---

## Features

- **Pal Database & Search:** Explore skills, stats, and elements with fast client-side indexing.
- **Deployed Pals Tracker:** Organize active base assignments and team compositions.
- **Responsive Interface:** Clean UI built with EJS templates and modern styling.

---

## Tech Stack

- **Backend:** Node.js, Express.js
- **Templating:** EJS
- **Styling:** CSS3, Vanilla JavaScript

---
